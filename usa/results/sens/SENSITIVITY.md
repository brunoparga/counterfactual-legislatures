# Does the 65% headline survive its parameters?

Generated by `usa/tools/sensitivity_table.py` from the scorings in
`usa/results/sens/`, each written by `usa/tools/score_matrix.py`.

## The gate

Every run below had to return **209 D / 226 R** for the enacted
113th-Congress plan on 2012 presidential votes. That plan is a real
map and does not depend on our parameters, so a different number
would mean the run was broken rather than that the answer had
changed.

3 of 5 runs passed. **Failed: uniform_span_cuberoot, uniform_span_wyoming.**

### Where the gate stopped us

- `uniform_span_cuberoot` returned 208 D / 222 R over 430 districts, missing AK, DE, MT, ND, SD.
- `uniform_span_wyoming` returned 208 D / 224 R over 432 districts, missing DE, MT, SD.

The cause is the same in both and it is a property of the
election data, not of the code. The seven states DRA publishes
no block file for — AK, DE, MT, ND, SD, VT, WY — are exactly
the states with one district, and a one-district state needs no
block data because its statewide total settles it exactly.
Raise the house size and those states need two districts, the
statewide shortcut stops applying, and they drop out of *every*
plan in the run — including the enacted one, which is why its
baseline moves when nothing about the enacted map has changed.

So **the house-size axis is not measurable with the election
data we hold**, and no numbers from those runs are reported
below. The remaining house-size combinations were not run once
the cause was established: they fail identically and for the
same reason.
